## Frameworks
- **Anthropic Claude Agent SDK** — build production agents with Claude.
- **LangGraph** — graph-based stateful agent orchestration.
- **LlamaIndex** — data framework for LLM/RAG apps.
- **CrewAI** — role-based multi-agent collaboration.
- **AutoGen** — conversational multi-agent framework.
- **Model Context Protocol (MCP)** — open standard to connect models to tools.

## Memory
- **Chroma**, **Pinecone**, **Weaviate**, **Qdrant** — vector stores.
- **Mem0**, **Zep** — long-term agent memory layers.
- Patterns: buffer / summary / vector / episodic memory.

## Tools & Function Calling
- Claude tool use & MCP servers.
- **Composio**, **Arcade** — managed tool catalogs for agents.

## RAG & Retrieval
- Hybrid search (BM25 + dense), re-ranking, query rewriting.
- Evaluation: **Ragas**, **TruLens**.

## Multi-Agent
- Orchestrator/worker, planner/executor, debate, reflection patterns.
- Handoff protocols & shared scratchpads.

## Observability & Eval
- **LangSmith**, **Langfuse**, **Phoenix (Arize)** — tracing & eval.
- Cost/latency tracking, regression suites.

## Papers
- *ReAct: Reasoning + Acting* (Yao et al.)
- *Reflexion: Language Agents with Verbal RL* (Shinn et al.)
- *Toolformer* (Schick et al.)
- *Generative Agents* (Park et al.)
